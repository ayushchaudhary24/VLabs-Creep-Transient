# Creep Transient Laboratory

Open `index.html` in a modern browser. No installation, server, or internet connection is required for the simulation. Audio uses available browser/device English voices.

- `index.html`: page structure and controls.
- `css/style.css`: layout, material colors, and blinking prompts.
- `js/script.js`: English/Hindi interface, English/off narration, experiment history, graphs, and 3D apparatus.
- `img/Al-graph.png`, `img/Nickel-graph.png`, `img/Platinum-graph.png`: original supplied reference graphs, displayed for English results. Hindi results retain translated vector labels.
- `js/vendor/three-bundle.js`: bundled Three.js 0.160.0 and OrbitControls, for offline use.
- `js/vendor/LICENSE-three.txt`: third-party license.
